About AirIntel

AirIntel is an end-to-end machine learning and web development project that predicts the Air Quality Index (AQI) using environmental, weather, and pollution data. The project was created to demonstrate the complete machine learning workflow—from feature engineering and model training to deployment within an interactive web application—while making AQI prediction accessible and easy to understand.

Why Manual Inputs?

Unlike commercial weather applications, AirIntel does not automatically fetch environmental data from live APIs. This is an intentional design decision made to emphasize the complete machine learning workflow rather than simply consuming external services.

By allowing users to provide the environmental parameters manually, the application demonstrates how different input features influence the prediction process and provides a better understanding of how machine learning models transform raw data into meaningful AQI predictions.
